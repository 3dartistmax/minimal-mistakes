Copy this file into `_artworks/` with a new filename, such as `my-new-artwork.md`.

```yaml
---
title: "Artwork title"
image: "/assets/images/your-image.jpg"
description: "Short description of your artwork"
---
```

Put the image in `assets/images/`. The gallery automatically displays every
file in `_artworks/`, so you can add as many artworks as you want.
